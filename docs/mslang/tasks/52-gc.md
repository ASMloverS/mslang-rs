# 垃圾回收（MVP：Young 代半空间复制 + Old 代 STW 标记-清除）

> **注意**：本任务实现 MVP 阶段的 GC（STW 标记-清除 + Young 代半空间复制）。完整的目标 GC 设计（并发三色标记清扫 + 分代回收）见 [14-gc](../14-gc.md)，将在 Phase 7.5（Task 64-66）增量升级。

## 所属阶段
Phase 2.5 - GC 基础

## 前置任务
22-object-system-collections, 23-vm-core

> **依赖说明（订正）**：本任务在 README 中位于 Phase 2.5，但根集扫描涉及的 VM 状态分散在后续任务：`CallFrame.closure`（task 28）、`open_upvalues`（task 28）、`defer_stack`（task 36）、`module_cache`（task 45）、`c_roots`（task 65）、`event_loop`/协程（task 53）。因此**根集扫描采用增量策略**：MVP 仅扫 `vm.stack` + `vm.globals` + `vm.frames`（不含 closure），其余根源**随对应 task 落地时**由该 task 追加扫描代码（见下方「根集增量扩展点」）。下方伪代码中所有 `vm.open_upvalues`/`vm.defer_stack`/`vm.module_cache`/`vm.c_roots`/`vm.event_loop`/`frame.closure` 的扫描块均为「占位，条件编译/feature-gated，未就绪时跳过」。

## 目标
实现 MVP 垃圾回收系统：Young 代使用半空间复制（Cheney 算法），Old 代使用 STW 标记-清除，per-协程 TLAB + Bump 分配，统一对象头 MsObjHeader。

## 设计规格

参照 [14-gc](../14-gc.md) § 实现路线、§ 对象内存布局、§ 堆内存组织、§ TLAB 分配、§ Minor GC：

### MVP 策略

| 属性 | MVP 值 |
|---|---|
| 核心算法 | Young 代半空间复制 + Old 代 STW 标记-清除 |
| 并发模型 | STW（无并发 GC 线程） |
| 分代策略 | 3 代：Young / Old / Immortal |
| 写屏障 | 无（MVP 阶段不启用） |
| 分配方式 | TLAB Bump 分配 |
| 对象头 | 统一 MsObjHeader（16 bytes） |

### Young 代半空间复制

- From-Space / To-Space 交替（默认各 4MB）
- 分配通过 TLAB 切分，Bump 指针分配
- Minor GC：存活对象从 From-Space 复制到 To-Space，交换空间
- 晋升：存活超过 `promotion_age`（默认 2）次 Minor GC 的对象晋升到 Old

### Old 代 STW 标记-清除

- free-list 管理
- Major GC：从根集出发标记所有可达对象，清除未标记对象
- 无并发、无写屏障

### 1. 统一对象头 MsObjHeader

`src/vm/gc.rs`：

参照 [14-gc](../14-gc.md) § 对象内存布局：

```rust
#[repr(C)]
struct MsObjHeader {
    gc_meta: u8,
    type_tag: u8,
    size: u16,
    _padding: u16,
    class_ptr: usize,
}
```

gc_meta 位域：

```
  7   6   5   4   3        2   1    0
┌───┬───┬───┬───┬───┬───────┬───┬────┐
│age│age│ P │ F │ - │ gen(2) │color(2)│
└───┴───┴───┴───┴───┴───────┴───┴────┘
```

| 位 | 字段 | 说明 |
|---|---|---|
| 0-1 | color | 三色标记：White(0)、Gray(1)、Black(2) |
| 2-3 | gen | 代数：Young(0)、Old(1)、Immortal(2) |
| 4 | has_finalizer | 是否注册了 finalizer |
| 5 | pinned | 是否被 C 侧 pin |
| 6-7 | age | 晋升年龄计数 |

```rust
impl MsObjHeader {
    const COLOR_MASK: u8 = 0b0000_0011;
    const GEN_MASK: u8 = 0b0000_1100;
    const GEN_SHIFT: u8 = 2;
    const HAS_FINALIZER: u8 = 0b0001_0000;
    const PINNED: u8 = 0b0010_0000;

    fn new(size: u16, type_tag: TypeTag) -> Self {
        Self {
            gc_meta: 0,
            type_tag: type_tag as u8,
            size,
            _padding: 0,
            class_ptr: 0,
        }
    }

    fn color(&self) -> Color {
        // 订正 R4：不用 transmute（位值 3 越界为 UB），安全 match + fallback。
        match self.gc_meta & Self::COLOR_MASK {
            0 => Color::White,
            1 => Color::Gray,
            2 => Color::Black,
            _ => Color::White, // 不可能；防御
        }
    }
    fn set_color(&mut self, c: Color) {
        self.gc_meta = (self.gc_meta & !Self::COLOR_MASK) | (c as u8);
    }
    fn generation(&self) -> Generation {
        match (self.gc_meta & Self::GEN_MASK) >> Self::GEN_SHIFT {
            0 => Generation::Young,
            1 => Generation::Old,
            2 => Generation::Immortal,
            _ => Generation::Young, // 不可能；防御
        }
    }
    fn set_generation(&mut self, g: Generation) {
        self.gc_meta = (self.gc_meta & !Self::GEN_MASK) | ((g as u8) << Self::GEN_SHIFT);
    }
    fn age(&self) -> u8 {
        self.gc_meta >> 6
    }
    fn inc_age(&mut self) {
        let a = self.age();
        if a < 3 { self.gc_meta = (self.gc_meta & 0b0011_1111) | ((a + 1) << 6); }
    }
}

#[repr(u8)]
enum Color { White = 0, Gray = 1, Black = 2 }

#[repr(u8)]
enum Generation { Young = 0, Old = 1, Immortal = 2 }
```

### 1.5 对象布局迁移：data_ptr → inline（必须先做）

> **订正 A1/A3**：task 20/22 现状中 MsList/MsDict/MsTuple/MsSet/MsStr 均为 `{ header, data_ptr: *mut T }`，载荷经 `Box::into_raw(Box::new(...))` **独立分配**。这与 `14-gc.md` § 对象内存布局及 `20-object-system-basic.md:188` 要求的「header 后紧跟数据的内联布局」**相反**。直接对 data_ptr 模型做 trace（误读载荷）与字节复制（共享 Boxed 缓冲 → 双重释放/UAF）均**不安全**。故本任务**必须先迁移对象布局为 inline**。

迁移目标（单次分配 = header + 载荷，`header.size` 含载荷）：

| 类型 | 迁移后布局（header 之后） | 字节可复制？ |
|---|---|---|
| String | `[u8]` 数据内联 | ✅ 纯字节 |
| List | `len: u32` + `[Object; len]` 内联 | ✅（Object 含 Ref 指针，由 forward 修正） |
| Tuple | `len: u32` + `[Object; len]` 内联 | ✅ |
| Dict | `DictMap`（HashMap，**含独立 bucket 缓冲**） | ❌ 需 per-type copy |
| Set | `HashSet<Object>`（**含独立 bucket 缓冲**） | ❌ 需 per-type copy |

因此 minor GC 的复制**不能**用 `copy_nonoverlapping(size)` 盲复制；改为 TypeDescriptor 提供 `copy_for_gc` 钩子（见 §2），逐类型正确复制载荷（Dict/Set 重新分配其内部 bucket），复制后由 forward 修正子 Ref 指针。

迁移同时须改造 task 20/22 的 `alloc_*`/`read_*` 函数：分配改为 `heap.alloc(size)`（返回 `*mut MsObjHeader`），载荷紧跟 header；`read_*` 改为 `(ptr as *mut u8).add(16) as *mut T`。MVP 过渡期允许 `alloc_*` 仍返回 `Object::Ref`，但底层经 GC 堆分配。

> **对 trace 的影响（订正 A1）**：迁移后 §2 的 trace 读 `(obj as *mut u8).add(16)` 即为内联载荷，正确。Dict/Set 的 trace 对内联 `DictMap`/`HashSet` 做**只读**迭代（不复制），仍正确。

### 4. TLAB 与 Bump 分配

```rust
struct TLAB {
    cursor: *mut u8,
    limit: *mut u8,
    size: usize,   // 与 14-gc.md § TLAB 结构一致
}

// 订正 A4：alloc_obj 透传 vm，供 refill 时触发 minor_gc。
fn alloc_obj(
    heap: &mut MsHeap, tlab: &mut TLAB, vm: &mut VM, size: usize, tag: TypeTag,
) -> *mut MsObjHeader {
    let aligned_size = (size + 7) & !7;

    // 大对象直接进入 LOS（参照 14-gc.md § LOS）
    if size > LARGE_OBJ_THRESHOLD {
        return alloc_los(heap, size, tag);
    }

    if tlab.cursor as usize + aligned_size <= tlab.limit as usize {
        let ptr = tlab.cursor as *mut MsObjHeader;
        tlab.cursor = unsafe { tlab.cursor.add(aligned_size) };
        unsafe {
            ptr.write(MsObjHeader::new(aligned_size as u16, tag));
        }
        return ptr;
    }

    refill_tlab_or_gc(heap, tlab, vm, aligned_size, tag)
}

/// 大对象分配（>32KB），独立分配，type_tag 设为 LARGE_OBJECT。
/// 参照 14-gc.md § 大对象空间。
/// 订正 R3/V4：真实字节数记入 LOS 侧表 `los_sizes`，dealloc 时据此构造 Layout
/// （header.size 置 0，不可用于 dealloc，否则零大小 Layout 为 UB）。
fn alloc_los(heap: &mut MsHeap, size: usize, tag: TypeTag) -> *mut MsObjHeader {
    let aligned_size = (size + 7) & !7;
    let layout = std::alloc::Layout::from_size_align(aligned_size, 8).unwrap();
    let ptr = unsafe { std::alloc::alloc(layout) } as *mut MsObjHeader;
    unsafe {
        ptr.write(MsObjHeader::new(0, TypeTag::LARGE_OBJECT));
        // 实际类型标签记录在 header 后的额外字节中
        (*ptr).class_ptr = tag as u64; // 复用 class_ptr 存储实际 TypeTag
    }
    heap.los_space.objects.push(ptr);
    heap.los_space.los_sizes.insert(ptr, aligned_size); // 侧表记录真实大小
    heap.los_space.bytes_used += aligned_size;
    ptr
}

fn refill_tlab_or_gc(
    heap: &mut MsHeap, tlab: &mut TLAB, vm: &mut VM, size: usize, tag: TypeTag,
) -> *mut MsObjHeader {
    if heap.young_cursor + TLAB_SIZE <= heap.young_from.len() {
        let base = unsafe { heap.young_from.as_mut_ptr().add(heap.young_cursor) };
        tlab.cursor = base;
        tlab.limit = unsafe { base.add(TLAB_SIZE) };
        heap.young_cursor += TLAB_SIZE;
        return alloc_obj(heap, tlab, vm, size, tag);
    }

    minor_gc(heap, vm);
    if heap.young_cursor + TLAB_SIZE <= heap.young_from.len() {
        let base = unsafe { heap.young_from.as_mut_ptr().add(heap.young_cursor) };
        tlab.cursor = base;
        tlab.limit = unsafe { base.add(TLAB_SIZE) };
        heap.young_cursor += TLAB_SIZE;
        return alloc_obj(heap, tlab, vm, size, tag);
    }

    alloc_old(heap, vm, size, tag)
}
```

### 5. Minor GC（Young 代半空间复制 — Cheney 算法）

```
1. STW
2. 扫描根集中指向 Young 的 Ref：
   - vm.stack（值栈）
   - vm.globals（全局变量）
   - vm.call_stack（调用栈中的闭包）
   - vm.open_upvalues（开放上值）
   - vm.defer_stack（defer 栈，参照 14-gc.md § 根集）
   - vm.module_cache（已加载模块）
   - vm.c_roots（C API 显式注册的根，参照 13-capi.md msPushRoot/msPopRoot）
   - vm.event_loop 中的暂停协程及其 Future.waiters
3. 存活对象从 From-Space 复制到 To-Space：
   - 更新所有指向该对象的引用
   - 对象 age += 1
   - age >= promotion_age → 复制到 Old 代
4. 交换 From-Space / To-Space
5. 重置 TLAB 指向新 From-Space
6. 恢复执行
```

```rust
// 订正 A5/A6/R6：
//  - minor_gc 取 vm: &mut VM（须改写根槽指针，&VM 不可）
//  - 不复用三色作「已访问」标志；改用独立 forwarding map（避免跨周期丢失存活）
//  - 复制经 TypeDescriptor.copy_for_gc 钩子（Dict/Set 等正确复制 bucket）
//  - promotion_age 先读到局部，避免与 alloc_old 的 &mut heap 借用冲突
fn minor_gc(heap: &mut MsHeap, vm: &mut VM) {
    for b in heap.young_to.iter_mut() { *b = 0; }
    let mut to_cursor: usize = 0;
    let promotion_age = heap.promotion_age;            // R6：先读局部
    let mut forwarded: HashMap<*mut MsObjHeader, *mut MsObjHeader> = HashMap::new();

    // 把 obj 复制到 to-space（或晋升 Old），返回新指针；幂等（已转发则直返）。
    let copy_to = |obj: *mut MsObjHeader,
                   heap: &mut MsHeap,
                   to_space: &mut [u8],
                   cursor: &mut usize| -> *mut MsObjHeader {
        if let Some(&np) = forwarded.get(&obj) { return np; }
        let header = unsafe { &mut *obj };
        header.inc_age();
        let new_ptr = if header.age() >= promotion_age {
            let old_ptr = alloc_old_raw(heap, header.size as usize);
            let n = (type_descriptor(header.type_tag).copy_for_gc)(obj, old_ptr);
            unsafe { (*old_ptr).set_generation(Generation::Old); (*old_ptr).size = n as u16; }
            forwarded.insert(obj, old_ptr);
            old_ptr
        } else {
            let np = unsafe { to_space.as_mut_ptr().add(*cursor) as *mut MsObjHeader };
            let n = (type_descriptor(header.type_tag).copy_for_gc)(obj, np);
            *cursor += n;
            unsafe { (*np).set_generation(Generation::Young); (*np).size = n as u16; }
            forwarded.insert(obj, np);
            np
        };
        new_ptr
    };

    // 订正 A5：forward 接收「槽」&mut Object，复制后改写槽指向新位置。
    let mut forward = |slot: &mut Object, heap: &mut MsHeap| {
        if let Object::Ref(r) = slot {
            let np = copy_to(*r, heap, &mut heap.young_to, &mut to_cursor);
            *slot = Object::Ref(np);
        }
    };

    // 根集（&mut 槽）。其余根源 feature-gated，见前置任务说明。
    for val in vm.stack.iter_mut() { forward(val, heap); }
    for val in vm.globals.values_mut() { forward(val, heap); }
    // 以下根源随对应 task 落地启用（未就绪时该字段不存在，条件编译跳过）：
    //   frame.closure（task 28）、open_upvalues（task 28）、defer_stack（task 36）、
    //   module_cache（task 45）、c_roots（task 65）、event_loop 协程（task 53）

    // Cheney 扫描：遍历 to-space，用 forward_fields 修正各对象内部槽。
    let mut scan: usize = 0;
    while scan < to_cursor {
        let obj = unsafe { heap.young_to.as_mut_ptr().add(scan) as *mut MsObjHeader };
        let n = unsafe { (*obj).size as usize };
        let ff = type_descriptor(unsafe { (*obj).type_tag }).forward_fields;
        ff(obj, &mut |slot| forward(slot, heap));
        scan += n;
    }

    std::mem::swap(&mut heap.young_from, &mut heap.young_to);
    heap.young_cursor = 0;
    heap.bytes_allocated = heap.bytes_allocated.saturating_sub(to_cursor);
}
```

### 6. Major GC（Old 代 STW 标记-清除）

```rust
fn major_gc(heap: &mut MsHeap, vm: &VM) {
    let mut gray_stack: Vec<*mut MsObjHeader> = Vec::new();

    fn mark(obj: *mut MsObjHeader, gray_stack: &mut Vec<*mut MsObjHeader>) {
        let header = unsafe { &mut *obj };
        if header.color() == Color::White {
            header.set_color(Color::Gray);
            gray_stack.push(obj);
        }
    }

    // 根集标记（增量：MVP 仅 stack+globals+frames；下列其余块为「占位，
    // feature-gated，对应 task 落地后启用，未就绪时该字段不存在须跳过」）。
    for val in vm.stack.iter() {
        if let Object::Ref(r) = val { mark(*r, &mut gray_stack); }
    }
    for val in vm.globals.values() {
        if let Object::Ref(r) = val { mark(*r, &mut gray_stack); }
    }
    // frames：MVP 的 CallFrame 无 closure 字段（task 28 起有）。
    // [task 28] for frame in vm.frames.iter() { if let Object::Ref(r) = &frame.closure { mark(*r,..); } }
    // [task 28] for upvalue in vm.open_upvalues.iter() { ... }
    // [task 36] for entry in vm.defer_stack.iter() { ... callee/args ... }
    // [task 45] for module in vm.module_cache.values() { ... }
    // [task 65] for root in vm.c_roots.iter() { ... }
    // [task 53] 暂停协程及其 Future.waiters

    while let Some(obj) = gray_stack.pop() {
        let header = unsafe { &mut *obj };
        let descriptor = type_descriptor(header.type_tag);
        (descriptor.trace)(obj, &mut |child| mark(child, &mut gray_stack));
        header.set_color(Color::Black);
    }

    heap.old_space.objects.retain(|&obj| {
        let header = unsafe { &mut *obj };
        if header.color() == Color::Black {
            header.set_color(Color::White);
            true
        } else {
            // 有 finalizer 的对象加入 finalizer 队列而非立即释放
            if header.gc_meta & MsObjHeader::HAS_FINALIZER != 0 {
                heap.finalizer_queue.push(obj);
                header.set_color(Color::White); // 复活，下次 GC 再回收
                true
            } else {
                let size = header.size as usize;
                heap.bytes_allocated = heap.bytes_allocated.saturating_sub(size); // R2
                unsafe {
                    let layout = std::alloc::Layout::from_size_align_unchecked(size, 8);
                    std::alloc::dealloc(obj as *mut u8, layout);
                }
                false
            }
        }
    });

    // LOS 大对象空间清除（参照 14-gc.md § LOS）
    heap.los_space.objects.retain(|&obj| {
        let header = unsafe { &mut *obj };
        if header.color() == Color::Black {
            header.set_color(Color::White);
            true
        } else {
            if header.gc_meta & MsObjHeader::HAS_FINALIZER != 0 {
                heap.finalizer_queue.push(obj);
                header.set_color(Color::White);
                true
            } else {
                // 订正 R3/V4：LOS 真实大小取自侧表 los_sizes（header.size 为 0，不可用）。
                let size = heap.los_space.los_sizes.remove(&obj).unwrap_or(0);
                heap.los_space.bytes_used = heap.los_space.bytes_used.saturating_sub(size);
                if size > 0 {
                    unsafe {
                        let layout = std::alloc::Layout::from_size_align_unchecked(size, 8);
                        std::alloc::dealloc(obj as *mut u8, layout);
                    }
                }
                false
            }
        }
    });

    // 订正 V6：major_gc（持 vm:&VM）只收集 finalizer_queue，不在 GC 内执行
    // 用户代码。finalizer 由 mutator 线程在 GC 结束后经 run_finalizers(&mut VM) 执行
    // （参照 14-gc.md § Finalize）。

    heap.next_major_gc = (heap.bytes_allocated as f64 * MAJOR_GC_RATIO) as usize;
}

/// GC 后由 mutator 线程执行 pending finalizers（须 &mut VM 以运行 mslang 代码）。
/// 参照 14-gc.md § Finalize（466-486）。订正 V5：执行后清 has_finalizer，
/// 否则复活对象每次 GC 都重跑 __del__。
fn run_finalizers(heap: &mut MsHeap, vm: &mut VM) {
    for obj in heap.finalizer_queue.drain(..) {
        let header = unsafe { &mut *obj };
        let tag = header.type_tag;
        let desc = type_descriptor(tag);
        if let Some(finalize) = desc.finalize {
            finalize(obj);
        }
        // Instance：调用用户定义的 __del__（task 41 落地后）
        if tag == TypeTag::INSTANCE as u8 {
            vm.call_user_finalizer(obj); // 需 &mut VM；GC 外调用，安全
        }
        // 清除 finalizer 标记，下次 GC 可正常回收（不再无限复活）
        header.gc_meta &= !MsObjHeader::HAS_FINALIZER;
        header.set_color(Color::White);
    }
}
```

### 7. GC 触发决策

```rust
// 订正 R5：Full GC = minor 后 major（非二选一）。finalizer 由 mutator 在 GC 后执行。
fn maybe_gc(heap: &mut MsHeap, vm: &mut VM) {
    let mut ran = false;
    if heap.bytes_allocated > heap.next_major_gc {
        minor_gc(heap, vm);
        major_gc(heap, vm);   // major 取 vm:&VM（仅读根集）
        ran = true;
    } else if heap.bytes_allocated > heap.next_minor_gc {
        minor_gc(heap, vm);
    }
    if ran {
        run_finalizers(heap, vm); // mutator 线程，GC 后执行
    }
}
```

### 8. GC 安全注意事项

- MVP 阶段使用 STW GC，无需写屏障
- `alloc_obj` 期间可能触发 GC，需确保所有中间状态中的 GC 指针已被 root
- `mark_roots` 必须覆盖所有根集：栈、全局变量、调用栈、开放上值、defer 栈、模块缓存、C API 根（**增量落地**：MVP 仅栈+全局+frames，余随对应 task）
- 内联小值（Int/Float/Bool/Nil）不需要 GC 管理，仅 `Ref(*mut MsObjHeader)` 需要跟踪
- 所有 17 种 TypeTag 必须有对应的 trace 函数，否则 GC 无法扫描对象内部引用→悬垂指针（Phase 4-7 涉及类型随对应 task 补真实 trace，当前以 noop 占位）
- 有 `has_finalizer` 标志的对象在回收前加入 finalizer 队列；finalizer 由 mutator 线程在 GC 后执行，**执行后清除 has_finalizer**（避免无限复活）
- 大对象（>32KB）通过 LOS 独立分配，真实大小记入 `los_sizes` 侧表（header.size 为 0），不经过 TLAB
- **对象布局迁移（§1.5）是 trace/复制正确性的前提**：未迁移则 GC 不安全
- **MVP 无写屏障 → Old→Young 跨代引用风险**：仅被 Old 引用的 Young 对象会被 minor GC 误回收。MVP 缓解：minor GC 时顺带扫描全部 Old 对象的 Young 指向（或简单禁用「Old 持有 Young」并强制晋升）。完整方案（Remembered Set / card table）随 task 62-64 并发 GC 引入写屏障时落地

## 验证标准

1. Young 代 Bump 分配正确工作
2. Minor GC 正确复制存活对象到 To-Space
3. 对象在达到 promotion_age 后正确晋升到 Old 代
4. Major GC 正确标记和清除不可达 Old 对象
5. GC 不回收可达对象（根集**增量覆盖**：MVP 栈+全局+frames；调用栈闭包/开放上值/defer 栈/模块缓存/C API 根/协程随对应 task 启用）
6. `bytes_allocated` 统计准确（用 `saturating_sub`，不可下溢）
7. GC 触发阈值工作正常
8. 循环引用被 Major GC 正确回收
9. 所有 17 种 TypeTag 有对应 trace 函数（Phase 4-7 类型 noop 占位，随对应 task 补真实 trace）
10. 大对象（>32KB）正确进入 LOS 空间分配和回收
11. 有 `__del__` 的对象被回收时触发 finalizer 执行

```rust
#[cfg(test)]
mod tests {
    use super::*;

    fn test_young_alloc() {
        let mut vm = VM::new();
        let heap = &mut vm.heap;
        let mut tlab = TLAB::empty();
        let ptr = alloc_obj(heap, &mut tlab, &mut vm, 24, TypeTag::STRING);

    fn test_minor_gc_copies_survivors() {
        // 根栈保留一个 list 引用，另分配一个不可达对象；触发 minor_gc。
        let mut vm = VM::new();
        let live = alloc_list(vec![Object::Int(1), Object::Int(2)]); // 经 GC 堆分配
        vm.stack.push(live.clone());
        let before = if let Object::Ref(r) = live { r } else { unreachable!() };
        minor_gc(&mut vm.heap, &mut vm);
        // 存活对象被复制：栈顶槽已更新为新地址，内容仍为 [1,2]
        let top = vm.stack.last().unwrap();
        let after = if let Object::Ref(r) = top { *r } else { unreachable!() };
        assert_ne!(before as usize, after as usize, "survivor should be forwarded");
        assert_eq!(read_list(after).clone(), vec![Object::Int(1), Object::Int(2)]);
    }

    #[test]
    fn test_promotion_to_old() {
        // 同一对象连续存活 promotion_age 次 minor_gc → 晋升 Old 代。
        let mut vm = VM::new();
        vm.heap.promotion_age = 2;
        vm.stack.push(alloc_list(vec![Object::Int(9)]));
        minor_gc(&mut vm.heap, &mut vm);
        minor_gc(&mut vm.heap, &mut vm);
        let r = if let Object::Ref(r) = vm.stack.last().unwrap() { *r } else { unreachable!() };
        assert_eq!(unsafe { (*r).generation() }, Generation::Old);
    }

    #[test]
    fn test_major_gc_collects_unreachable() {
        // 在 Old 代分配对象但不留根引用，触发 major_gc，验证被回收。
        let mut vm = VM::new();
        let before = vm.heap.old_space.objects.len();
        alloc_old(&mut vm.heap, &mut vm, 24, TypeTag::STRING); // 不入根
        let _ = before; // 仅占位：具体断言依 alloc_old 是否登记 objects
        major_gc(&mut vm.heap, &mut vm);
        // 不可达对象应被清除（bytes_allocated 不应包含它）
```

# 垃圾回收（MVP：Young 代半空间复制 + Old 代 STW 标记-清除）

> **注意**：本任务实现 MVP 阶段的 GC（STW 标记-清除 + Young 代半空间复制）。完整的目标 GC 设计（并发三色标记清扫 + 分代回收）见 [14-gc](../14-gc.md)，将在 Phase 7.5（Task 64-66）增量升级。

## 所属阶段
Phase 2.5 - GC 基础

## 前置任务
22-object-system-collections, 23-vm-core, 27-call-frame

## 目标
实现 MVP 垃圾回收系统：Young 代使用半空间复制（Cheney 算法），Old 代使用 STW 标记-清除，per-协程 TLAB + Bump 分配，统一对象头 MsObjHeader。

## 设计规格

参照 [14-gc](../14-gc.md) § 实现路线、§ 对象内存布局、§ 堆内存组织、§ TLAB 分配、§ Minor GC：

### MVP 策略

| 属性 | MVP 值 |
|---|---|
| 核心算法 | Young 代半空间复制 + Old 代 STW 标记-清除 |
| 并发模型 | STW（无并发 GC 线程） |
| 分代策略 | 3 代：Young / Old / Immortal |
| 写屏障 | 无（MVP 阶段不启用） |
| 分配方式 | TLAB Bump 分配 |
| 对象头 | 统一 MsObjHeader（16 bytes） |

### Young 代半空间复制

- From-Space / To-Space 交替（默认各 4MB）
- 分配通过 TLAB 切分，Bump 指针分配
- Minor GC：存活对象从 From-Space 复制到 To-Space，交换空间
- 晋升：存活超过 `promotion_age`（默认 2）次 Minor GC 的对象晋升到 Old

### Old 代 STW 标记-清除

- free-list 管理
- Major GC：从根集出发标记所有可达对象，清除未标记对象
- 无并发、无写屏障

## 实现细节

### 1. 统一对象头 MsObjHeader

`src/vm/gc.rs`：

参照 [14-gc](../14-gc.md) § 对象内存布局：

```rust
#[repr(C)]
struct MsObjHeader {
    gc_meta: u8,
    type_tag: u8,
    size: u16,
    _padding: u16,
    class_ptr: usize,
}
```

gc_meta 位域：

```
  7   6   5   4   3        2   1    0
┌───┬───┬───┬───┬───┬───────┬───┬────┐
│ R │ P │ F │ - │ gen(2bit) │color(2)│
└───┴───┴───┴───┴───┴───────┴───┴────┘
```

| 位 | 字段 | 说明 |
|---|---|---|
| 0-1 | color | White(0)、Gray(1)、Black(2) |
| 2-3 | gen | Young(0)、Old(1)、Immortal(2) |
| 4 | reserved | — |
| 5 | has_finalizer | 是否注册了 finalizer |
| 6 | pinned | 是否被 pin |
| 7 | reserved | — |

```rust
impl MsObjHeader {
    const COLOR_MASK: u8 = 0b0000_0011;
    const GEN_MASK: u8 = 0b0000_1100;
    const GEN_SHIFT: u8 = 2;
    const HAS_FINALIZER: u8 = 0b0001_0000;
    const PINNED: u8 = 0b0010_0000;

    fn new(size: u16, type_tag: TypeTag) -> Self {
        Self {
            gc_meta: 0,
            type_tag: type_tag as u8,
            size,
            _padding: 0,
            class_ptr: 0,
        }
    }

    fn color(&self) -> Color {
        unsafe { std::mem::transmute(self.gc_meta & Self::COLOR_MASK) }
    }
    fn set_color(&mut self, c: Color) {
        self.gc_meta = (self.gc_meta & !Self::COLOR_MASK) | (c as u8);
    }
    fn generation(&self) -> Generation {
        unsafe { std::mem::transmute((self.gc_meta & Self::GEN_MASK) >> Self::GEN_SHIFT) }
    }
    fn set_generation(&mut self, g: Generation) {
        self.gc_meta = (self.gc_meta & !Self::GEN_MASK) | ((g as u8) << Self::GEN_SHIFT);
    }
    fn age(&self) -> u8 {
        self.gc_meta >> 6
    }
    fn inc_age(&mut self) {
        let a = self.age();
        if a < 3 { self.gc_meta = (self.gc_meta & 0b0011_1111) | ((a + 1) << 6); }
    }
}

#[repr(u8)]
enum Color { White = 0, Gray = 1, Black = 2 }

#[repr(u8)]
enum Generation { Young = 0, Old = 1, Immortal = 2 }

#[repr(u8)]
enum TypeTag {
    STRING = 1, LIST = 2, DICT = 3, TUPLE = 4, SET = 5,
    FUNCTION = 6, CLOSURE = 7, CLASS = 8, INSTANCE = 9,
    MODULE = 10, ITERATOR = 11, GENERATOR = 12,
    BOUND_METHOD = 15, LARGE_OBJECT = 0xFF,
}
```

### 4. TLAB 与 Bump 分配

```rust
struct TLAB {
    cursor: *mut u8,
    limit: *mut u8,
}

fn alloc_obj(heap: &mut MsHeap, tlab: &mut TLAB, size: usize, tag: TypeTag) -> *mut MsObjHeader {
    let aligned_size = (size + 7) & !7;

    if tlab.cursor as usize + aligned_size <= tlab.limit as usize {
        let ptr = tlab.cursor as *mut MsObjHeader;
        tlab.cursor = unsafe { tlab.cursor.add(aligned_size) };
        unsafe {
            ptr.write(MsObjHeader::new(aligned_size as u16, tag));
        }
        return ptr;
    }

    refill_tlab_or_gc(heap, tlab, aligned_size, tag)
}

fn refill_tlab_or_gc(
    heap: &mut MsHeap, tlab: &mut TLAB, size: usize, tag: TypeTag,
) -> *mut MsObjHeader {
    if heap.young_cursor + TLAB_SIZE <= heap.young_from.len() {
        let base = unsafe { heap.young_from.as_mut_ptr().add(heap.young_cursor) };
        tlab.cursor = base;
        tlab.limit = unsafe { base.add(TLAB_SIZE) };
        heap.young_cursor += TLAB_SIZE;
        return alloc_obj(heap, tlab, size, tag);
    }

    minor_gc(heap);
    if heap.young_cursor + TLAB_SIZE <= heap.young_from.len() {
        let base = unsafe { heap.young_from.as_mut_ptr().add(heap.young_cursor) };
        tlab.cursor = base;
        tlab.limit = unsafe { base.add(TLAB_SIZE) };
        heap.young_cursor += TLAB_SIZE;
        return alloc_obj(heap, tlab, size, tag);
    }

    alloc_old(heap, size, tag)
}
```

### 5. Minor GC（Young 代半空间复制 — Cheney 算法）

```
1. STW
2. 扫描根集（栈、全局变量、调用栈、开放上值）中指向 Young 的 Ref
3. 存活对象从 From-Space 复制到 To-Space：
   - 更新所有指向该对象的引用
   - 对象 age += 1
   - age >= promotion_age → 复制到 Old 代
4. 交换 From-Space / To-Space
5. 重置 TLAB 指向新 From-Space
6. 恢复执行
```

```rust
fn minor_gc(heap: &mut MsHeap, vm: &VM) {
    heap.young_to.iter_mut().for_each(|b| *b = 0);
    let mut to_cursor: usize = 0;

    let scan_ptr = |obj: *mut MsObjHeader, to_space: &mut [u8], cursor: &mut usize| -> *mut MsObjHeader {
        let header = unsafe { &mut *obj };
        let obj_size = header.size as usize;
        let new_ptr = unsafe { to_space.as_mut_ptr().add(*cursor) as *mut MsObjHeader };
        unsafe {
            std::ptr::copy_nonoverlapping(obj as *const u8, new_ptr as *mut u8, obj_size);
        }
        *cursor += obj_size;
        new_ptr
    };

    let forward = |obj: &mut *mut MsObjHeader, to_space: &mut [u8], cursor: &mut usize| {
        let header = unsafe { &mut **obj };
        if header.color() == Color::White && header.generation() == Generation::Young {
            header.set_color(Color::Black);
            header.inc_age();
            let new_ptr = if header.age() >= heap.promotion_age {
                let old_ptr = alloc_old_raw(heap, header.size as usize);
                unsafe {
                    std::ptr::copy_nonoverlapping(
                        *obj as *const u8, old_ptr as *mut u8, header.size as usize
                    );
                }
                old_ptr
            } else {
                scan_ptr(*obj, to_space, cursor)
            };
            unsafe { (*new_ptr).set_color(Color::Black); }
            *obj = new_ptr;
        }
    };

    let to_space = &mut heap.young_to;

    for val in vm.stack.iter() {
        if let Object::Ref(r) = val {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }
    for val in vm.globals.values() {
        if let Object::Ref(r) = val {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }
    for frame in vm.call_stack.iter() {
        if let Object::Ref(r) = &frame.closure {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }

    std::mem::swap(&mut heap.young_from, &mut heap.young_to);
    heap.young_cursor = 0;
    heap.bytes_allocated = heap.bytes_allocated.saturating_sub(to_cursor);
}
```

### 6. Major GC（Old 代 STW 标记-清除）

```rust
fn major_gc(heap: &mut MsHeap, vm: &VM) {
    let mut gray_stack: Vec<*mut MsObjHeader> = Vec::new();

    fn mark(obj: *mut MsObjHeader, gray_stack: &mut Vec<*mut MsObjHeader>) {
        let header = unsafe { &mut *obj };
        if header.color() == Color::White {
            header.set_color(Color::Gray);
            gray_stack.push(obj);
        }
    }

    for val in vm.stack.iter() {
        if let Object::Ref(r) = val { mark(*r, &mut gray_stack); }
    }
    for val in vm.globals.values() {
        if let Object::Ref(r) = val { mark(*r, &mut gray_stack); }
    }
    for frame in vm.call_stack.iter() {
        if let Object::Ref(r) = &frame.closure { mark(*r, &mut gray_stack); }
    }
    for upvalue in vm.open_upvalues.iter() {
        if let Object::Ref(r) = upvalue { mark(*r, &mut gray_stack); }
    }

    while let Some(obj) = gray_stack.pop() {
        let header = unsafe { &mut *obj };
        let descriptor = type_descriptor(header.type_tag);
        (descriptor.trace)(obj, &mut |child| mark(child, &mut gray_stack));
        header.set_color(Color::Black);
    }

    heap.old_space.objects.retain(|&obj| {
        let header = unsafe { &mut *obj };
        if header.color() == Color::Black {
            header.set_color(Color::White);
            true
        } else {
            heap.bytes_allocated -= header.size as usize;
            unsafe { drop(Box::from_raw(obj as *mut u8)); }
            false
        }
    });

    heap.next_major_gc = (heap.bytes_allocated as f64 * MAJOR_GC_RATIO) as usize;
}
```

### 7. GC 触发决策

```rust
fn maybe_gc(heap: &mut MsHeap, vm: &VM) {
    if heap.bytes_allocated > heap.next_major_gc {
        major_gc(heap, vm);
    } else if heap.bytes_allocated > heap.next_minor_gc {
        minor_gc(heap, vm);
    }
}
```

### 8. GC 安全注意事项

- MVP 阶段使用 STW GC，无需写屏障
- `alloc_obj` 期间可能触发 GC，需确保所有中间状态中的 GC 指针已被 root
- `mark_roots` 必须覆盖所有根集：栈、全局变量、调用栈、开放上值
- 内联小值（Int/Float/Bool/Nil）不需要 GC 管理，仅 `Ref(*mut MsObjHeader)` 需要跟踪

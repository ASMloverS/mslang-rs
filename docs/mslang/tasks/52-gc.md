# 垃圾回收（MVP：Young 代半空间复制 + Old 代 STW 标记-清除）

> **注意**：本任务实现 MVP 阶段的 GC（STW 标记-清除 + Young 代半空间复制）。完整的目标 GC 设计（并发三色标记清扫 + 分代回收）见 [14-gc](../14-gc.md)，将在 Phase 7.5（Task 64-66）增量升级。

## 所属阶段
Phase 2.5 - GC 基础

## 前置任务
22-object-system-collections, 23-vm-core, 27-call-frame

## 目标
实现 MVP 垃圾回收系统：Young 代使用半空间复制（Cheney 算法），Old 代使用 STW 标记-清除，per-协程 TLAB + Bump 分配，统一对象头 MsObjHeader。

## 设计规格

参照 [14-gc](../14-gc.md) § 实现路线、§ 对象内存布局、§ 堆内存组织、§ TLAB 分配、§ Minor GC：

### MVP 策略

| 属性 | MVP 值 |
|---|---|
| 核心算法 | Young 代半空间复制 + Old 代 STW 标记-清除 |
| 并发模型 | STW（无并发 GC 线程） |
| 分代策略 | 3 代：Young / Old / Immortal |
| 写屏障 | 无（MVP 阶段不启用） |
| 分配方式 | TLAB Bump 分配 |
| 对象头 | 统一 MsObjHeader（16 bytes） |

### Young 代半空间复制

- From-Space / To-Space 交替（默认各 4MB）
- 分配通过 TLAB 切分，Bump 指针分配
- Minor GC：存活对象从 From-Space 复制到 To-Space，交换空间
- 晋升：存活超过 `promotion_age`（默认 2）次 Minor GC 的对象晋升到 Old

### Old 代 STW 标记-清除

- free-list 管理
- Major GC：从根集出发标记所有可达对象，清除未标记对象
- 无并发、无写屏障

### 1. 统一对象头 MsObjHeader

`src/vm/gc.rs`：

参照 [14-gc](../14-gc.md) § 对象内存布局：

```rust
#[repr(C)]
struct MsObjHeader {
    gc_meta: u8,
    type_tag: u8,
    size: u16,
    _padding: u16,
    class_ptr: usize,
}
```

gc_meta 位域：

```
  7   6   5   4   3        2   1    0
┌───┬───┬───┬───┬───┬───────┬───┬────┐
│age│age│ P │ F │ - │ gen(2) │color(2)│
└───┴───┴───┴───┴───┴───────┴───┴────┘
```

| 位 | 字段 | 说明 |
|---|---|---|
| 0-1 | color | 三色标记：White(0)、Gray(1)、Black(2) |
| 2-3 | gen | 代数：Young(0)、Old(1)、Immortal(2) |
| 4 | has_finalizer | 是否注册了 finalizer |
| 5 | pinned | 是否被 C 侧 pin |
| 6-7 | age | 晋升年龄计数 |

```rust
impl MsObjHeader {
    const COLOR_MASK: u8 = 0b0000_0011;
    const GEN_MASK: u8 = 0b0000_1100;
    const GEN_SHIFT: u8 = 2;
    const HAS_FINALIZER: u8 = 0b0001_0000;
    const PINNED: u8 = 0b0010_0000;

    fn new(size: u16, type_tag: TypeTag) -> Self {
        Self {
            gc_meta: 0,
            type_tag: type_tag as u8,
            size,
            _padding: 0,
            class_ptr: 0,
        }
    }

    fn color(&self) -> Color {
        unsafe { std::mem::transmute(self.gc_meta & Self::COLOR_MASK) }
    }
    fn set_color(&mut self, c: Color) {
        self.gc_meta = (self.gc_meta & !Self::COLOR_MASK) | (c as u8);
    }
    fn generation(&self) -> Generation {
        unsafe { std::mem::transmute((self.gc_meta & Self::GEN_MASK) >> Self::GEN_SHIFT) }
    }
    fn set_generation(&mut self, g: Generation) {
        self.gc_meta = (self.gc_meta & !Self::GEN_MASK) | ((g as u8) << Self::GEN_SHIFT);
    }
    fn age(&self) -> u8 {
        self.gc_meta >> 6
    }
    fn inc_age(&mut self) {
        let a = self.age();
        if a < 3 { self.gc_meta = (self.gc_meta & 0b0011_1111) | ((a + 1) << 6); }
    }
}

#[repr(u8)]
enum Color { White = 0, Gray = 1, Black = 2 }

#[repr(u8)]
enum Generation { Young = 0, Old = 1, Immortal = 2 }
```

```rust
    let list = unsafe { &*((obj as *mut u8).add(16) as *mut Vec<Object>) };

    }

    }

unsafe fn trace_closure(
    ptr: *mut MsObjHeader,
    callback: &mut dyn FnMut(*mut *mut MsObjHeader),
) {
    let closure = ptr as *const Closure;
    callback(&mut (*closure).function as *mut _);
    for up in (*closure).upvalues.iter_mut() {
        callback(up as *mut *mut MsObjHeader);
    }
}

fn trace_class(obj: *mut MsObjHeader, callback: &mut dyn FnMut(*mut MsObjHeader)) {
    let class = unsafe { &*((obj as *mut u8).add(16) as *mut MsClass) };
    // trace 父类
    if let Some(parent) = &class.parent {
        if let Object::Ref(r) = parent { callback(*r); }
    }
    // trace 方法表中的闭包
    for method in class.methods.values() {
        if let Object::Ref(r) = method { callback(*r); }
    }
}

fn trace_instance(obj: *mut MsObjHeader, callback: &mut dyn FnMut(*mut MsObjHeader)) {
    let inst = unsafe { &*((obj as *mut u8).add(16) as *mut MsInstance) };
    callback(inst.class_ptr);
    for val in inst.fields.values() {
        if let Object::Ref(r) = val { callback(*r); }
    }
}

fn trace_module(obj: *mut MsObjHeader, callback: &mut dyn FnMut(*mut MsObjHeader)) {
    let module = unsafe { &*((obj as *mut u8).add(16) as *mut MsModule) };
    for val in module.globals.values() {
        if let Object::Ref(r) = val { callback(*r); }
    }
}

fn trace_generator(obj: *mut MsObjHeader, callback: &mut dyn FnMut(*mut MsObjHeader)) {
    let gen = unsafe { &*((obj as *mut u8).add(16) as *mut MsGenerator) };
    // trace 闭包引用
    if let Object::Ref(r) = &gen.closure { callback(*r); }
    // trace 独立栈中的引用
    for val in gen.stack.iter() {
        if let Object::Ref(r) = val { callback(*r); }
    }
    // trace yield from 子迭代器
    if let Some(Object::Ref(r)) = &gen.receiver { callback(*r); }
}

fn trace_bound_method(obj: *mut MsObjHeader, callback: &mut dyn FnMut(*mut MsObjHeader)) {
    let bm = unsafe { &*((obj as *mut u8).add(16) as *mut MsBoundMethod) };
    if let Object::Ref(r) = &bm.instance { callback(*r); }
    if let Object::Ref(r) = &bm.method { callback(*r); }
}

fn trace_future(obj: *mut MsObjHeader, callback: &mut dyn FnMut(*mut MsObjHeader)) {
    let fut = unsafe { &*((obj as *mut u8).add(16) as *mut MsFuture) };
    // trace 等待者的回调引用
    if let Some(Object::Ref(r)) = &fut.result { callback(*r); }

    for val in ch.buffer.iter() {
        if let Object::Ref(r) = val { callback(*r); }
    }
}

fn trace_join_handle(obj: *mut MsObjHeader, callback: &mut dyn FnMut(*mut MsObjHeader)) {
    // JoinHandle 持有协程的返回值引用（如果已完成）
```

### 4. TLAB 与 Bump 分配

```rust
struct TLAB {
    cursor: *mut u8,
    limit: *mut u8,
}

fn alloc_obj(heap: &mut MsHeap, tlab: &mut TLAB, size: usize, tag: TypeTag) -> *mut MsObjHeader {
    let aligned_size = (size + 7) & !7;

    // 大对象直接进入 LOS（参照 14-gc.md § LOS）
    if size > LARGE_OBJ_THRESHOLD {
        return alloc_los(heap, size, tag);
    }

    if tlab.cursor as usize + aligned_size <= tlab.limit as usize {
        let ptr = tlab.cursor as *mut MsObjHeader;
        tlab.cursor = unsafe { tlab.cursor.add(aligned_size) };
        unsafe {
            ptr.write(MsObjHeader::new(aligned_size as u16, tag));
        }
        return ptr;
    }

    refill_tlab_or_gc(heap, tlab, aligned_size, tag)
}

/// 大对象分配（>32KB），独立分配，type_tag 设为 LARGE_OBJECT。
/// 参照 14-gc.md § 大对象空间。
fn alloc_los(heap: &mut MsHeap, size: usize, tag: TypeTag) -> *mut MsObjHeader {
    let aligned_size = (size + 7) & !7;
    let layout = std::alloc::Layout::from_size_align(aligned_size, 8).unwrap();
    let ptr = unsafe { std::alloc::alloc(layout) } as *mut MsObjHeader;
    unsafe {
        ptr.write(MsObjHeader::new(0, TypeTag::LARGE_OBJECT));
        // 实际类型标签记录在 header 后的额外字节中
        (*ptr).class_ptr = tag as u64; // 复用 class_ptr 存储实际 TypeTag
    }
    heap.los_space.objects.push(ptr);
    heap.los_space.bytes_used += aligned_size;
    ptr
}

fn refill_tlab_or_gc(
    heap: &mut MsHeap, tlab: &mut TLAB, size: usize, tag: TypeTag, vm: &mut VM,
) -> *mut MsObjHeader {
    if heap.young_cursor + TLAB_SIZE <= heap.young_from.len() {
        let base = unsafe { heap.young_from.as_mut_ptr().add(heap.young_cursor) };
        tlab.cursor = base;
        tlab.limit = unsafe { base.add(TLAB_SIZE) };
        heap.young_cursor += TLAB_SIZE;
        return alloc_obj(heap, tlab, size, tag);
    }

    minor_gc(heap, vm);
    if heap.young_cursor + TLAB_SIZE <= heap.young_from.len() {
        let base = unsafe { heap.young_from.as_mut_ptr().add(heap.young_cursor) };
        tlab.cursor = base;
        tlab.limit = unsafe { base.add(TLAB_SIZE) };
        heap.young_cursor += TLAB_SIZE;
        return alloc_obj(heap, tlab, size, tag);
    }

    alloc_old(heap, size, tag)
}
```

### 5. Minor GC（Young 代半空间复制 — Cheney 算法）

```
1. STW
2. 扫描根集中指向 Young 的 Ref：
   - vm.stack（值栈）
   - vm.globals（全局变量）
   - vm.call_stack（调用栈中的闭包）
   - vm.open_upvalues（开放上值）
   - vm.defer_stack（defer 栈，参照 14-gc.md § 根集）
   - vm.module_cache（已加载模块）
   - vm.c_roots（C API 显式注册的根，参照 13-capi.md msPushRoot/msPopRoot）
   - vm.event_loop 中的暂停协程及其 Future.waiters
3. 存活对象从 From-Space 复制到 To-Space：
   - 更新所有指向该对象的引用
   - 对象 age += 1
   - age >= promotion_age → 复制到 Old 代
4. 交换 From-Space / To-Space
5. 重置 TLAB 指向新 From-Space
6. 恢复执行
```

```rust
fn minor_gc(heap: &mut MsHeap, vm: &VM) {
    heap.young_to.iter_mut().for_each(|b| *b = 0);
    let mut to_cursor: usize = 0;

    let scan_ptr = |obj: *mut MsObjHeader, to_space: &mut [u8], cursor: &mut usize| -> *mut MsObjHeader {
        let header = unsafe { &mut *obj };
        let obj_size = header.size as usize;
        let new_ptr = unsafe { to_space.as_mut_ptr().add(*cursor) as *mut MsObjHeader };
        unsafe {
            std::ptr::copy_nonoverlapping(obj as *const u8, new_ptr as *mut u8, obj_size);
        }
        *cursor += obj_size;
        new_ptr
    };

    let forward = |obj: &mut *mut MsObjHeader, to_space: &mut [u8], cursor: &mut usize| {
        let header = unsafe { &mut **obj };
        if header.color() == Color::White && header.generation() == Generation::Young {
            header.set_color(Color::Black);
            header.inc_age();
            let new_ptr = if header.age() >= heap.promotion_age {
                let old_ptr = alloc_old_raw(heap, header.size as usize);
                unsafe {
                    std::ptr::copy_nonoverlapping(
                        *obj as *const u8, old_ptr as *mut u8, header.size as usize
                    );
                }
                old_ptr
            } else {
                scan_ptr(*obj, to_space, cursor)
            };
            unsafe { (*new_ptr).set_color(Color::Black); }
            *obj = new_ptr;
        }
    };

    let to_space = &mut heap.young_to;

    for val in vm.stack.iter() {
        if let Object::Ref(r) = val {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }
    for val in vm.globals.values() {
        if let Object::Ref(r) = val {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }
    for frame in vm.call_stack.iter() {
        if let Object::Ref(r) = &frame.closure {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }
    // 开放上值
    for upvalue in vm.open_upvalues.iter() {
        if let Object::Ref(r) = upvalue {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }
    // defer 栈（参照 14-gc.md § 根集）
    for entry in vm.defer_stack.iter() {
        if let Object::Ref(r) = &entry.callee {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
        for arg in &entry.args {
            if let Object::Ref(r) = arg {
                forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
            }
        }
    }
    // 模块缓存
    for module in vm.module_cache.values() {
        if let Object::Ref(r) = module {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }
    // C API 显式注册的根
    for root in vm.c_roots.iter() {
        if let Object::Ref(r) = root {
            forward(&mut (*r as *mut MsObjHeader), to_space, &mut to_cursor);
        }
    }

    // Cheney scan: scan copied objects for internal references
    let mut scan: usize = 0;
    while scan < to_cursor {
        let obj = unsafe { heap.young_to.as_mut_ptr().add(scan) as *mut MsObjHeader };
        let obj_size = unsafe { (*obj).size as usize };
        let desc = type_descriptor(unsafe { (*obj).type_tag });
        (desc.trace)(obj, &mut |child| {
            forward(child, to_space, &mut to_cursor);
        });
        scan += obj_size;
    }

    std::mem::swap(&mut heap.young_from, &mut heap.young_to);
    heap.young_cursor = 0;
    heap.bytes_allocated = heap.bytes_allocated.saturating_sub(to_cursor);
}
```

### 6. Major GC（Old 代 STW 标记-清除）

```rust
fn major_gc(heap: &mut MsHeap, vm: &VM) {
    let mut gray_stack: Vec<*mut MsObjHeader> = Vec::new();

    fn mark(obj: *mut MsObjHeader, gray_stack: &mut Vec<*mut MsObjHeader>) {
        let header = unsafe { &mut *obj };
        if header.color() == Color::White {
            header.set_color(Color::Gray);
            gray_stack.push(obj);
        }
    }

    for val in vm.stack.iter() {
        if let Object::Ref(r) = val { mark(*r, &mut gray_stack); }
    }
    for val in vm.globals.values() {
        if let Object::Ref(r) = val { mark(*r, &mut gray_stack); }
    }
    for frame in vm.call_stack.iter() {
        if let Object::Ref(r) = &frame.closure { mark(*r, &mut gray_stack); }
    }
    for upvalue in vm.open_upvalues.iter() {
        if let Object::Ref(r) = upvalue { mark(*r, &mut gray_stack); }
    }
    // defer 栈
    for entry in vm.defer_stack.iter() {
        if let Object::Ref(r) = &entry.callee { mark(*r, &mut gray_stack); }
        for arg in &entry.args {
            if let Object::Ref(r) = arg { mark(*r, &mut gray_stack); }
        }
    }
    // 模块缓存
    for module in vm.module_cache.values() {
        if let Object::Ref(r) = module { mark(*r, &mut gray_stack); }
    }
    // C API 根
    for root in vm.c_roots.iter() {
        if let Object::Ref(r) = root { mark(*r, &mut gray_stack); }
    }

    while let Some(obj) = gray_stack.pop() {
        let header = unsafe { &mut *obj };
        let descriptor = type_descriptor(header.type_tag);
        (descriptor.trace)(obj, &mut |child| mark(child, &mut gray_stack));
        header.set_color(Color::Black);
    }

    heap.old_space.objects.retain(|&obj| {
        let header = unsafe { &mut *obj };
        if header.color() == Color::Black {
            header.set_color(Color::White);
            true
        } else {
            // 有 finalizer 的对象加入 finalizer 队列而非立即释放
            if header.gc_meta & MsObjHeader::HAS_FINALIZER != 0 {
                heap.finalizer_queue.push(obj);
                header.set_color(Color::White); // 复活，下次 GC 再回收
                true
            } else {
                let size = header.size as usize;
                heap.bytes_allocated -= size;
                unsafe {
                    let layout = std::alloc::Layout::from_size_align_unchecked(size, 8);
                    std::alloc::dealloc(obj as *mut u8, layout);
                }
                false
            }
        }
    });

    // LOS 大对象空间清除（参照 14-gc.md § LOS）
    heap.los_space.objects.retain(|&obj| {
        let header = unsafe { &mut *obj };
        if header.color() == Color::Black {
            header.set_color(Color::White);
            true
        } else {
            if header.gc_meta & MsObjHeader::HAS_FINALIZER != 0 {
                heap.finalizer_queue.push(obj);
                header.set_color(Color::White);
                true
            } else {
                // LOS 大对象大小由 LOS 单独记录
                heap.los_space.bytes_used -= header.size as usize;
                unsafe {
                    let layout = std::alloc::Layout::from_size_align_unchecked(
                        heap.los_space.obj_size(obj), 8);
                    std::alloc::dealloc(obj as *mut u8, layout);
                }
                false
            }
        }
    });

    // 执行 finalizer 队列中的 __del__ 方法（参照 14-gc.md § finalizer、06-oop.md § __del__）
    for obj in heap.finalizer_queue.drain(..) {
        let header = unsafe { &*obj };
        let desc = type_descriptor(header.type_tag);
        if let Some(finalize) = desc.finalize {
            finalize(obj);
        }
        // 对于 Instance，检查并调用用户定义的 __del__
        if header.type_tag == TypeTag::INSTANCE as u8 {
            vm.call_user_finalizer(obj); // 调用 instance.__del__()
        }
    }

    heap.next_major_gc = (heap.bytes_allocated as f64 * MAJOR_GC_RATIO) as usize;
}
```

### 7. GC 触发决策

```rust
fn maybe_gc(heap: &mut MsHeap, vm: &VM) {
    if heap.bytes_allocated > heap.next_major_gc {
        major_gc(heap, vm);
    } else if heap.bytes_allocated > heap.next_minor_gc {
        minor_gc(heap, vm);
    }
}
```

### 8. GC 安全注意事项

- MVP 阶段使用 STW GC，无需写屏障
- `alloc_obj` 期间可能触发 GC，需确保所有中间状态中的 GC 指针已被 root
- `mark_roots` 必须覆盖所有根集：栈、全局变量、调用栈、开放上值、defer 栈、模块缓存、C API 根
- 内联小值（Int/Float/Bool/Nil）不需要 GC 管理，仅 `Ref(*mut MsObjHeader)` 需要跟踪
- 所有 17 种 TypeTag 必须有对应的 trace 函数，否则 GC 无法扫描对象内部引用→悬垂指针
- 有 `has_finalizer` 标志的对象在回收前加入 finalizer 队列，调用 `__del__` 或 C finalizer
- 大对象（>32KB）通过 LOS 独立分配，不经过 TLAB

## 验证标准

1. Young 代 Bump 分配正确工作
2. Minor GC 正确复制存活对象到 To-Space
3. 对象在达到 promotion_age 后正确晋升到 Old 代
4. Major GC 正确标记和清除不可达 Old 对象
5. GC 不回收可达对象（根集覆盖：栈、全局、调用栈、开放上值、defer 栈、模块缓存、C API 根）
6. `bytes_allocated` 统计准确
7. GC 触发阈值工作正常
8. 循环引用被 Major GC 正确回收
9. 所有 17 种 TypeTag 有对应 trace 函数（GC 扫描无遗漏）
10. 大对象（>32KB）正确进入 LOS 空间分配和回收
11. 有 `__del__` 的对象被回收时触发 finalizer 执行

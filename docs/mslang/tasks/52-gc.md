# 垃圾回收（引用计数 + 标记-清除）

## 所属阶段
Phase 6.3 - 垃圾回收

## 前置任务
22-object-system-collections, 28-closures

## 目标
实现混合垃圾回收策略：引用计数处理常规内存回收，标记-清除 GC 处理循环引用，确保所有不可达对象被正确回收。

## 设计规格

参照 [11-bytecode-vm](../11-bytecode-vm.md) § 垃圾回收：

### 策略：引用计数 + 标记-清除

#### 引用计数

- 每个 `Gc<T>` 包含引用计数
- `Gc::clone()` 增加计数
- `Gc::drop()` 减少计数
- 计数归零时立即释放

#### 标记-清除 GC

- 引用计数无法处理循环引用
- 定期运行标记-清除 GC 清理循环引用
- 触发条件：`bytes_allocated > next_gc`

#### 标记-清除流程

1. **标记阶段**：从根集（栈、全局变量、调用栈、开放上值）出发，递归标记所有可达对象
2. **清除阶段**：遍历所有已分配对象，释放未标记的对象
3. **重置**：清除所有对象的标记

### GarbageCollector 结构

```rust
struct GarbageCollector {
    objects: Vec<GcBox>,
    bytes_allocated: usize,
    next_gc: usize,
    gray_stack: Vec<GcBox>,
}
```

## 实现细节

### 1. GcBox 定义

`src/vm/gc.rs`：

```rust
struct GcBox {
    header: GcHeader,
    data: GcData,
}

struct GcHeader {
    ref_count: usize,
    is_marked: bool,
    obj_type: GcType,
}

enum GcData {
    String(String),
    List(Vec<Object>),
    Dict(DictMap),
    Set(HashSet<Object>),
    Tuple(Vec<Object>),
    Function(Function),
    Closure(Closure),
    Class(Class),
    Instance(Instance),
    Module(Module),
    Iterator(Iterator),
    Generator(Generator),
    Future(Future),
    Channel(Channel),
    BoundMethod(BoundMethod),
    FileHandle(FileHandle),
}
```

- `ref_count`：引用计数
- `is_marked`：标记-清除的标记位
- `obj_type`：类型标识，用于 `Trace` trait 分派

### 2. Gc<T> 智能指针

```rust
struct Gc<T> {
    ptr: NonNull<GcBox>,
    _marker: PhantomData<T>,
}

impl<T> Clone for Gc<T> {
    fn clone(&self) -> Self {
        self.ptr.header.ref_count += 1;
        Gc { ptr: self.ptr, _marker: PhantomData }
    }
}

impl<T> Drop for Gc<T> {
    fn drop(&mut self) {
        self.ptr.header.ref_count -= 1;
        if self.ptr.header.ref_count == 0 {
            // 引用计数归零，立即释放
            // 注意：如果对象包含循环引用，不会立即释放
            // 标记-清除 GC 会处理
            unsafe { drop(Box::from_raw(self.ptr.as_ptr())); }
        }
    }
}
```

### 3. Trace trait

为所有可包含引用的对象实现 `Trace` trait：

```rust
trait Trace {
    fn trace(&self, gc: &mut GarbageCollector) {
        // 默认空实现（叶子类型如 String 无需 trace）
    }
}
```

各类型的 `Trace` 实现：

```rust
impl Trace for Vec<Object> {
    fn trace(&self, gc: &mut GarbageCollector) {
        for obj in self.iter() {
            obj.trace(gc);
        }
    }
}

impl Trace for Closure {
    fn trace(&self, gc: &mut GarbageCollector) {
        self.function.trace(gc);
        for upvalue in &self.upvalues {
            upvalue.trace(gc);
        }
    }
}

impl Trace for Instance {
    fn trace(&self, gc: &mut GarbageCollector) {
        self.class.trace(gc);
        for val in self.fields.values() {
            val.trace(gc);
        }
    }
}
```

### 4. GarbageCollector 实现

```rust
impl GarbageCollector {
    const INITIAL_GC_THRESHOLD: usize = 1024 * 1024; // 1MB

    fn new() -> Self {
        Self {
            objects: Vec::new(),
            bytes_allocated: 0,
            next_gc: Self::INITIAL_GC_THRESHOLD,
            gray_stack: Vec::new(),
        }
    }

    fn allocate(&mut self, obj: GcBox) -> GcPtr {
        let size = obj.size();
        self.bytes_allocated += size;
        let ptr = GcPtr::new(obj);
        self.objects.push(ptr);

        if self.bytes_allocated > self.next_gc {
            self.collect(vm);
        }
        ptr
    }

    fn collect(&mut self, vm: &VM) {
        // 标记阶段
        self.mark_roots(vm);
        self.trace_references();

        // 清除阶段
        self.sweep();

        // 调整阈值
        self.next_gc = self.bytes_allocated * 2;
    }

    fn mark_roots(&mut self, vm: &VM) {
        // 栈上的值
        for val in vm.stack.iter() {
            self.mark(val);
        }
        // 全局变量
        for val in vm.globals.values() {
            self.mark(val);
        }
        // 调用栈中的闭包
        for frame in vm.call_stack.iter() {
            self.mark(&frame.closure);
        }
        // 开放上值
        for upvalue in vm.open_upvalues.iter() {
            self.mark(upvalue);
        }
    }

    fn mark(&mut self, obj: &Object) {
        let gc_box = obj.as_gc_box();
        if gc_box.header.is_marked { return; }
        gc_box.header.is_marked = true;
        self.gray_stack.push(gc_box);
    }

    fn trace_references(&mut self) {
        while let Some(obj) = self.gray_stack.pop() {
            obj.data.trace(self);
        }
    }

    fn sweep(&mut self) {
        self.objects.retain(|obj| {
            if obj.header.is_marked {
                obj.header.is_marked = false;
                true
            } else {
                self.bytes_allocated -= obj.size();
                false // 释放
            }
        });
    }
}
```

### 5. GC 安全注意事项

- `allocate` 期间可能触发 GC，需确保所有中间状态中的 GC 指针已被 root
- `mark_roots` 必须覆盖所有根集：栈、全局变量、调用栈、开放上值
- MVP 阶段使用 stop-the-world GC，无需写屏障

## 验证标准

1. 引用计数正确追踪对象生命周期
2. 简单场景下不可达对象被立即回收（引用计数）
3. 循环引用被标记-清除 GC 正确回收
4. GC 不回收可达对象（不会 use-after-free）
5. `bytes_allocated` 统计准确
6. GC 触发阈值工作正常

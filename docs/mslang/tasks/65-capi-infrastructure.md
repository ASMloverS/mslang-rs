# C API 基础设施（cbindgen + 手写类型头文件 + 构建集成）

## 所属阶段
Phase 6 — 模块系统 + 标准库

## 前置任务
52-gc, 45-module-system

## 目标
搭建 C API 基础设施：cbindgen 配置、手写 types.h 核心类型定义、umbrella 头文件 mslang.h、build.rs 集成、Rust 侧 `src/capi/` 模块框架。所有后续 C API 任务（66-74）依赖本任务。

## 设计规格

参照 [13-capi](../13-capi.md) § 头文件结构、§ 版本宏、§ 平台兼容性宏、§ types.h 核心类型：

### 头文件结构

```
include/mslang/
├── mslang.h              // umbrella，include 全部子头文件
├── types.h               // 手写：核心类型定义、枚举、宏、版本号
├── vm.h                  // cbindgen 生成（Task 67）
├── value.h               // cbindgen 生成（Task 68）
├── call.h                // cbindgen 生成（Task 69）
├── error.h               // cbindgen 生成（Task 70）
├── module.h              // cbindgen 生成（Task 71）
└── class.h               // cbindgen 生成（Task 72）
```

### 职责划分

| 文件 | 生成方式 | 内容 |
|---|---|---|
| types.h | **手写** | 版本宏、平台宏、不透明类型、函数指针类型、枚举、布尔常量 |
| mslang.h | **手写** | umbrella 头文件，include types.h |
| vm.h ~ class.h | **cbindgen** | 从 `src/capi/*.rs` 的 `#[no_mangle] pub extern "C"` 函数自动生成 |

## 实现细节

### 1. cbindgen 配置 — cbindgen.toml

项目根目录下创建 `cbindgen.toml`：

```toml
language = "C"
include_guard = "MSLANG_H"
autogen_warning = "/* Warning: this file is auto-generated by cbindgen. Do not modify manually. */"
tab_width = 4
style = "tag"
include_version = true

[defines]
"feature = capi" = "MS_CAPI_ENABLED"

[export]
include = [
    "MsStatus",
    "MsType",
    "MsGcType",
    "MsFutureState",
]

[fn]
prefix = "MS_API"

[struct]
rename_fields = "SnakeCase"

[enum]
prefix_with_name = true
rename_variants = "ScreamingSnakeCase"

[parse]
parse_deps = false
include = ["mslang"]

[parse.expand]
crates = ["mslang"]
features = ["capi"]
```

### 2. Cargo.toml 变更

```toml
[package]
name = "mslang"
version = "0.1.0"
edition = "2021"

[features]
capi = []

[lib]
crate-type = ["cdylib", "rlib"]

[build-dependencies]
cbindgen = "0.26"
```

- `capi` feature：条件编译 C API 模块，不影响默认构建
- `cdylib`：生成 C 动态链接库（`.dll` / `.so` / `.dylib`）
- `rlib`：保留普通 Rust 库构建
- `cbindgen` build-dependency：`build.rs` 中调用，从 Rust 源码生成 C 头文件

### 3. build.rs

项目根目录下创建 `build.rs`：

```rust
fn main() {
    #[cfg(feature = "capi")]
    {
        let crate_dir = std::env::var("CARGO_MANIFEST_DIR").unwrap();
        let config = cbindgen::Config::from_file("cbindgen.toml")
            .expect("Unable to read cbindgen.toml");

        let bindings = cbindgen::Builder::new()
            .with_crate(crate_dir)
            .with_config(config)
            .generate();

        match bindings {
            Ok(bindings) => {
                let include_dir = std::path::Path::new("include/mslang");
                let _ = std::fs::create_dir_all(include_dir);

                let hand_written = ["types.h", "mslang.h"];

                let modules = [
                    ("vm", "vm.h"),
                    ("value", "value.h"),
                    ("call", "call.h"),
                    ("error", "error.h"),
                    ("module", "module.h"),
                    ("class", "class.h"),
                    ("gc", "gc.h"),
                ];

                for (module_name, filename) in &modules {
                    let mut builder = cbindgen::Builder::new()
                        .with_crate(&std::env::var("CARGO_MANIFEST_DIR").unwrap())
                        .with_config(config.clone());

                    builder = builder
                        .with_src(format!("src/capi/{}.rs", module_name));

                    if let Ok(module_bindings) = builder.generate() {
                        let out_path = include_dir.join(filename);
                        if !hand_written.contains(&filename.as_str()) {
                            module_bindings.write_to_file(&out_path);
                        }
                    }
                }
            }
            Err(e) => {
                eprintln!("cbindgen warning: {}", e);
            }
        }
    }
}
```

行为：
- 仅在 `--features capi` 时执行 cbindgen 生成
- 不覆盖手写文件（types.h、mslang.h）
- cbindgen 不可用时打印警告，不中断构建
- 从 `src/capi/` 各子模块生成对应头文件

### 4. include/mslang/types.h（手写）

```c
#ifndef MS_TYPES_H
#define MS_TYPES_H

#include <stdint.h>
#include <stddef.h>

/* ── Version ── */

#define MS_VERSION_MAJOR  0
#define MS_VERSION_MINOR  1
#define MS_VERSION_PATCH  0
#define MS_VERSION        "0.1.0"

#define MS_VERSION_AT_LEAST(major, minor, patch)              \
    (MS_VERSION_MAJOR > (major) ||                             \
     (MS_VERSION_MAJOR == (major) && MS_VERSION_MINOR > (minor)) || \
     (MS_VERSION_MAJOR == (major) && MS_VERSION_MINOR == (minor) && \
      MS_VERSION_PATCH >= (patch)))

/* ── Platform macros ── */

#ifdef _WIN32
  #ifdef MS_BUILDING
    #define MS_API __declspec(dllexport)
  #else
    #define MS_API __declspec(dllimport)
  #endif
#else
  #define MS_API __attribute__((visibility("default")))
#endif

#ifdef _WIN32
  #define MS_MODULE_INIT __declspec(dllexport)
#else
  #define MS_MODULE_INIT __attribute__((visibility("default")))
#endif

/* ── Opaque types ── */

typedef struct MsVM MsVM;
typedef struct MsValue MsValue;

/* ── Function pointer types ── */

typedef MsValue* (*MsCFunction)(MsVM* vm, MsValue* const* args, int nargs);
typedef void (*MsAsyncFunction)(MsVM* vm, MsValue* const* args, int nargs,
    MsValue* future);
typedef void (*MsFinalizerFn)(MsVM* vm, MsValue* obj, void* userdata);

/* ── Enums ── */

typedef enum MsType {
    MS_TYPE_NIL          = 0,
    MS_TYPE_BOOL         = 1,
    MS_TYPE_INT          = 2,
    MS_TYPE_FLOAT        = 3,
    MS_TYPE_STRING       = 4,
    MS_TYPE_LIST         = 5,
    MS_TYPE_DICT         = 6,
    MS_TYPE_TUPLE        = 7,
    MS_TYPE_SET          = 8,
    MS_TYPE_FUNCTION     = 9,
    MS_TYPE_CLASS        = 10,
    MS_TYPE_INSTANCE     = 11,
    MS_TYPE_MODULE       = 12,
    MS_TYPE_GENERATOR    = 13,
    MS_TYPE_FUTURE       = 14,
    MS_TYPE_CHANNEL      = 15,
    MS_TYPE_ITERATOR     = 16,
    MS_TYPE_BOUND_METHOD = 17,
    MS_TYPE_JOIN_HANDLE  = 18,
} MsType;

typedef enum MsStatus {
    MS_OK    =  0,
    MS_ERROR = -1,
    MS_YIELD =  1,
} MsStatus;

typedef enum MsGcType {
    MS_GC_MINOR = 0,
    MS_GC_MAJOR = 1,
    MS_GC_FULL  = 2,
} MsGcType;

typedef enum MsFutureState {
    MS_FUTURE_PENDING  = 0,
    MS_FUTURE_RESOLVED = 1,
    MS_FUTURE_REJECTED = 2,
} MsFutureState;

/* ── Boolean constants ── */

#define MS_TRUE  1
#define MS_FALSE 0

#endif /* MS_TYPES_H */
```

### 5. include/mslang/mslang.h（手写 umbrella）

```c
#ifndef MSLANG_H
#define MSLANG_H

#include "types.h"

/* The following headers are generated by cbindgen from src/capi/ modules.
 * They will be uncommented as each API module is implemented.
 *
 * #include "vm.h"
 * #include "value.h"
 * #include "call.h"
 * #include "error.h"
 * #include "module.h"
 * #include "class.h"
 * #include "gc.h"

```

- 初始阶段 include 注释状态，后续任务（67-72）逐步取消注释
- 使用者只需 `#include <mslang.h>` 或 `#include <mslang/mslang.h>`

## 验证标准

1. `cargo build` 编译无错误（默认不启用 capi）
2. `cargo build --features capi` 编译无错误（启用 capi 模块框架）
3. `include/mslang/types.h` 是合法 C 头文件（包含守卫、宏定义、类型定义完整）
4. `include/mslang/mslang.h` 正确 include types.h
5. cbindgen 可正常运行，不报错（即使生成内容为空）
6. `cargo test --features capi` 通过

8. `src/capi/` 模块结构与 [12-implementation-plan](../12-implementation-plan.md) 一致
9. 不启用 `capi` feature 时，`src/capi/` 不参与编译
